# Preview Notes

The package includes four **static composition references** in `preview/` for quick inspection of hierarchy and line-color direction.

These static renders are not authoritative browser acceptance because the container browser blocks loopback/private preview URLs and the static renderer does not execute JavaScript or perfectly reproduce absolutely-positioned WebP media.

Final acceptance must be performed in Codespaces browser after installation, especially for:

- hero product media;
- catalog JS rendering;
- line-page product rendering;
- mobile navigation;
- 390px layout;
- testimonial ticker motion;
- cart/order/B2B runtime behavior.

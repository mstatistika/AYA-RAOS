# Preview Notes

`preview/index-1366-refinement.png` is a static composition reference for the refined first viewport. It is **not** the browser acceptance artifact.

Actual acceptance must be done from the Codespaces preview URL using the installed source.

## What to verify

### Homepage
- AYA RAOS is understood before Sambal AYA is interpreted as the whole brand.
- All three lines are visible in the first viewport.
- Sambal AYA still has a clear conversion route.
- Three line gateways are readable and distinct without feeling like three unrelated brands.

### Line pages
- Line proposition is customer-facing; no public `Spice Red / Farm Green / Warm Amber` labels.
- `AYA RAOS` parent connection is visible.
- Other lines can be discovered without returning through browser Back.
- Product cards load from the canonical AYA product data.

### Product detail
- Owning line appears in breadcrumb and product heading context.
- Line link returns to the correct line gateway.
- Variant/cart behavior remains unchanged.
